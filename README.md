# JSU College of Liberal Arts Impact Report

Static editorial website for Jackson State University College of Liberal Arts' Fall 2023-Spring 2026 impact report.

## Publishing

The production site is served from the repository root by GitHub Pages. It uses plain HTML, CSS, and JavaScript and requires no login, application runtime, database, or build step.

## Source of truth

- `index.html` contains the editorial page structure.
- `styles.css` contains the responsive visual system.
- `script.js` contains the strategic-priority content and interactions.
- `impact-report-2023-2026.pdf` is the downloadable source report.
